# 군BTI MVP PRD

## 목표

사용자가 짧은 성향 설문을 완료하면, 군 직무군과의 적합도 및 이해하기 쉬운 근거를 보여준다. 서비스는 진로 탐색 도구이며 공식 인사·선발 시스템이 아니다.

## 대상 사용자

- 입대를 앞두었거나 군 직무를 탐색 중인 한국어 사용자
- 모바일에서 5~10분 안에 결과를 확인하고 싶은 사용자

## MVP 범위

1. 소개와 안내, 개인정보·면책 고지
2. 초기 10문항(검증 후 20~30문항으로 확장)의 단일 선택 설문과 진행률
3. 상위 3개 직무군, 성향 요약, 추천 이유, 주의사항
4. 선택적 로그인 및 결과 저장
5. 운영자용 질문·선택지·직무 데이터 관리

## 비범위

- 실제 병과/보직 배정, 지원 자격 판정, 군 인사 데이터 연동
- 건강·정치 성향·정밀 위치 같은 민감 정보 수집
- 추천 결과를 근거로 한 자동 의사결정

## 성공 기준

- 설문 시작 대비 완료율 60% 이상
- 결과 페이지 로딩 2초 이내(일반 네트워크 기준)
- 추천 이유를 읽은 사용자 비율과 재방문율을 익명 집계

## 핵심 사용자 흐름

소개 → 고지 확인 → 설문 → 점수 계산 → 결과 → (선택) 로그인 후 결과 저장 → 다른 결과 탐색
