# MVP 구현 계획

## 아키텍처

Next.js App Router가 UI와 서버 로직을 함께 제공한다. Supabase는 Auth와 PostgreSQL을 맡고, Vercel은 Git 기반 Preview/Production 배포를 맡는다. `lib/supabase`의 브라우저·서버 클라이언트만 사용해 인증 세션을 관리한다.

## 라우트

| 단계 | 라우트 | 역할 |
| --- | --- | --- |
| 1 | `/` | 소개 및 설문 시작 |
| 2 | `/test` | 설문 진행과 임시 답변 저장 |
| 3 | `/result/[id]` | 성향·추천 결과 |
| 4 | `/login` | 선택적 로그인 |
| 5 | `/admin` | 운영 데이터 관리(관리자만) |

## 단계별 작업

1. **기반 완료**: 프로젝트, shadcn/ui, Supabase 경계, 문서, 초기 스키마를 구성한다. *(현재 완료)*
2. **설문**: 질문 조회, 진행률, 유효성 검사, 세션 임시 저장, 접근성 키보드 조작을 구현한다.
3. **추천**: 서버에서 점수 계산하고 결과·추천 근거를 저장한다. 알고리즘 단위 테스트를 작성한다.
4. **인증·관리**: 로그인, 사용자 결과 목록, 관리자 권한/RLS, 질문과 직무 CRUD를 구현한다.
5. **출시 준비**: 오류 추적, 분석(동의 기반), 성능·접근성 검증, 법률 문구, Preview 테스트 후 배포한다.

## 테스트 전략

- 계산 함수: 경계값, 동점, 알고리즘 버전 단위 테스트
- 설문 흐름: 미응답·새로고침·중단 뒤 복귀 E2E 테스트
- 인증/RLS: 비로그인·일반 사용자·관리자 권한 테스트
- 배포: PR마다 Vercel Preview에서 모바일/데스크톱 핵심 흐름 점검
