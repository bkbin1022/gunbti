# 디자인 시스템

## 방향

차분하고 명료한 안내 서비스. 군대 이미지를 과도하게 차용하지 않고, 신뢰·탐색·개인성을 우선한다.

## 토큰

- 기본 배경: `stone-50`, 표면: `white`, 본문: `stone-950`
- 주요 행동: `emerald-700`, 보조 강조: `emerald-100`
- 모서리: 카드 `rounded-2xl`, 버튼은 기본 `rounded-md` 또는 주요 CTA `rounded-full`
- 본문은 최소 16px, 보조 텍스트는 충분한 대비를 유지한다.

## 컴포넌트 원칙

- shadcn/ui를 기본으로 쓰며 변형은 도메인 컴포넌트에서 제한한다.
- 설문은 한 화면에 한 문항, 진행률·이전·다음·저장 상태를 모두 제공한다.
- 오류와 비어 있는 상태는 원인과 다음 행동을 한국어로 분명히 안내한다.
- 키보드 조작, 포커스 표시, 라벨과 aria 설명을 유지한다.
