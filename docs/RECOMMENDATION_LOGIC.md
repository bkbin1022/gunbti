# 추천 로직

## 성향 차원 초안

- 협업 ↔ 독립 수행
- 현장 활동 ↔ 체계·분석
- 안정·절차 ↔ 변화·문제 해결
- 기술·장비 ↔ 사람·지원

각 선택지는 차원별 `-2`~`+2` 점수를 갖는다. 사용자의 합산 점수를 0~100으로 정규화하고, 직무군의 목표 프로필과 가중 절대거리로 비교한다.

```text
적합도 = 100 - Σ(차원 가중치 × |사용자 점수 - 직무 목표 점수|)
```

점수 동점은 설명 가능성이 높은 직무(일치한 상위 차원이 많은 직무)를 우선한다. 결과에는 상위 3개와 일치한 성향 2~3개를 제시한다.

## 안전 원칙

- 직무명·자격·병과 정보는 공식 공개 자료 확인 후 갱신한다.
- 점수만으로 적합/부적합을 단정하지 않는다.
- 결과는 추천 근거, 한계, 공식 상담 경로를 함께 보여 준다.
- 알고리즘 수정 시 `algorithm_version`을 올리고 이전 결과를 재계산하지 않는다.
